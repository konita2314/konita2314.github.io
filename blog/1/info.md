## 关于本站

这是 Konita 个人主页重构后的第一篇示例文章。博客内容放在 `blog/{id}/` 目录下：

- `info.txt`：元信息（key: value 行格式：title / date / excerpt / cover / lastModified）
- `info.md`：正文（Markdown）

## 支持的功能

### 代码高亮

```ts
const greeting: string = '你好，世界'
console.log(greeting)
```

### 中文标题目录

点击右下角悬浮的 📑 按钮可以打开目录，中文标题可以正常跳转。
